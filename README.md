# Windows Server 2025 Active Directory Enterprise Lab

A comprehensive 7-day hands-on enterprise infrastructure lab built using VMware, Windows Server 2025, and Windows 11.

## Lab Overview & Architecture
* **Environment:** VMware Workstation (NAT Network)
* **Domain:** `Fady.local`
* **Nodes:** 
  * `DC01` (Windows Server 2025 - Active Directory Domain Controller, DNS, DHCP, File Server)
  * `PC01` (Windows 11 - Domain Joined Workstation)

## Implementation Summary
* **Day 01:** Initial Server Setup, Static IP Configuration, and Server Manager deployment.
* **Day 02:** Active Directory Domain Services (AD DS) installation and forest promotion (`Fady.local`).
* **Day 03:** Organizational Units (OUs) structure design and User/Computer object management.
* **Day 04:** Group Policy Objects (GPOs) configuration and deployment.
* **Day 05:** File Server implementation, Shared Folders, and NTFS/Share Permissions.
* **Day 06:** DHCP Server scope configuration and IP lease management.
* **Day 07:** Domain joining Windows 11 client and final infrastructure verification.
